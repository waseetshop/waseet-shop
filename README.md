# وسيط شوب | Waseet Shop

موقع وكالة وسيط شوب لتصميم وتطوير المواقع والمنصات الرقمية للشركات والمؤسسات الصغيرة والمتوسطة.

## المزايا

- واجهة عربية متجاوبة بالكامل
- عرض خدمات تطوير المواقع والمتاجر وتطبيقات الويب
- معرض أعمال بمشاريع فعلية
- شرح واضح لمنهجية العمل
- نموذج طلب استشارة وتسعيرة
- بيانات مشاركة اجتماعية وصورة Open Graph مخصصة

## التشغيل محليًا

يتطلب المشروع Node.js بإصدار 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في نافذة التشغيل.

## التحقق من نسخة الإنتاج

```bash
npm run build
```

## التقنيات

- Next.js وReact
- TypeScript
- Tailwind CSS
- vinext وCloudflare Workers
